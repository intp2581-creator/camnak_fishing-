# 게임 아이템 자체 결제 설계 (kreft.co.kr)

> 2026-09-01 작성 · 아임웹을 거치지 않고 게임 홈페이지에서 결제까지 끝내는 구조
> 카카오페이 요구사항: **1개 도메인 내에서 상품 선택 → 결제수단 선택 → 결제 진행**

---

## 1. 흐름

```
게임(Flutter) 상점 [구매]
        │  이메일은 이미 로그인 상태로 알고 있음
        ↓
kreft.co.kr/store.html          상품 진열 (현재 hub/store.html 재사용)
        ↓  [구매하기]
kreft.co.kr/checkout.html       주문서 · 결제수단 선택 · 약관 동의
        ↓  결제창 (포트원 SDK)
      토스페이 / 카드 / 카카오 / 네이버
        ↓  결제 완료 → imp_uid 반환
Cloud Function  payVerify       ⭐ 서버 검증 (핵심)
        │  ① 포트원 API로 실제 결제금액 조회
        │  ② 우리 DB의 상품가격과 대조
        │  ③ 불일치 = 즉시 취소
        ↓
      주문 저장 + 아이템 즉시 지급
        ↓
kreft.co.kr/done.html           완료 안내 → 게임으로 돌아가기
```

**아임웹 대비 개선점**: 지급이 1분 폴링이 아니라 **즉시**. 도메인 이동 없음.

## 3. 만들 것

### 3-1. 화면 (kreft.co.kr)
| 파일 | 내용 |
|---|---|
| `store.html` | 이미 있음. 구매 버튼만 checkout으로 |
| `checkout.html` | 주문서 · 결제수단 · 약관 동의 · 결제창 호출 |
| `done.html` | 결제 완료/실패 안내 |
| `orders.html` | 내 구매 내역 · 환불 신청 |

### 3-2. Cloud Functions
| 함수 | 역할 |
|---|---|
| `payPrepare` | 주문번호 발급 · 금액을 서버에 선기록 |
| `payVerify` | ⭐ 결제 검증 → 지급. 금액 불일치 시 자동 취소 |
| `payWebhook` | 포트원 웹훅(가상계좌 입금·취소 등 사후 통지) |
| `payRefund` | 환불 실행(관리자 승인 후) |
| `myOrders` | 내 주문 조회 |

### 3-3. Firestore
```
config/products/{itemKey}     가격·조건·지급방식 (서버 기준값)
orders/{orderId}              주문 1건
  ├ uid, email, itemKey, amount
  ├ status: ready|paid|failed|refund_req|refunded
  ├ impUid, pgProvider, method
  └ grantedAt, refundedAt
refund_requests/{id}          환불 요청(관리자 승인 대기)
```

## 4. 보안 — 반드시 지킬 것

1. **금액은 서버에서만** 결정. 클라이언트 전달값 신뢰 금지
2. `payVerify`에서 **포트원 API로 실제 결제액 재조회** 후 대조
3. 불일치·중복 → **즉시 결제 취소** + 지급 안 함
4. `orders/{orderId}` **멱등 처리** (같은 주문 두 번 지급 방지 — 지금 `processed_orders`와 동일 원리)
5. 지급은 **Cloud Function만** 수행. 클라이언트가 인벤토리를 직접 못 건드리게
6. 포트원 API Secret은 `functions/.env` (절대 클라이언트 노출 금지)

## 6. 순서

```
1. 결제 페이지 + 검증 함수 개발      ← 도메인 없이도 가능
2. kreft.co.kr DNS 전파 완료 대기
3. 배포 → 실제 결제 흐름 확인
4. PG 심사 신청 (카카오·이니시스·네이버·토스)
5. 승인되는 대로 결제수단 하나씩 켜기
6. 게임 상점 구매버튼 주소 교체 → 아임웹 졸업
```

**1번은 지금 시작 가능.** 도메인·PG 없이 포트원 테스트 모드로 전 구간 검증할 수 있다.
